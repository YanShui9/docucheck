# 资料与采购品目对应：B 中文前端交付

日期：2026-10-10。实施基线为本地提交 `f9c8b90`。本步完成[已批准设计](superpowers/specs/2026-10-10-document-item-binding-design.md)的前端B，按[前端计划](superpowers/plans/2026-10-10-document-item-binding-frontend.md)执行，完成测试和独立只读复审后随本步提交本地Git。业务迁移、服务应用和真实闭环C尚未执行。

## 用户可执行的操作

1. 在资料面板的供应商报价、规格资料中点击“关联采购品目”。买方需求资料用于整理审查清单，不显示该关联入口。历史快照和只读成员显示“查看品目对应”。
2. 从当前已确认清单选择采购品目，指定整份单品文件、XLSX矩形范围或PDF连续页面。整份文件必须另外勾选“只描述此单一品目”，不会自动把文件名当作依据。
3. 选择同一文件中支持品目的原文摘录，必要时核对原件。品目依据可以在数值范围外，但不扩大正式审查的数值来源范围。
4. 明确上传时的旧产品标识属于品目名称、具体型号／SKU还是未知。SKU另有独立原文依据，不与采购品目混用。
5. 增删改先进入本地待确认清单。核对完整清单、确认理由并明确勾选后才保存；同一请求保留其他文件的所有当前对应条目。
6. 保存成功会使旧审查结果进入历史状态，提示重新发起审查。本次确认不会自动调用模型，也不会直接修改旧报告结论。

本步骤采用既有白灰背景、绿色强调和资料面板，不改主要聊天布局。编辑器与原件面板按需加载。

## 代码与状态约束

- `frontend/src/itemBindings.ts`：独立类型和请求契约，沿用OIDC请求入口；保存携带资料、清单、对应关系三个预期版本以及已确认清单ID。只发送允许的请求字段，不回传服务器展开的证据集合或指纹。
- `frontend/src/itemBindingForm.ts`：选择器边界、原文连续摘录、旧标识分类与SKU校验。真正的权限、语义支持、跨范围和冲突判定仍由服务端负责。
- `DocumentItemBindings.vue`：完整清单本地编辑、明确确认、原文分页、内嵌原件、当前与历史状态、同键重试和作用域隔离。
- `DocumentsPanel.vue`：中文入口与对应状态，读取失败显示不可读取；其他文件解析状态变化不会清空当前编辑。
- `App.vue` / `ChatWorkspace.vue`：保存成功的通知由根组件接收；即使关闭资料面板，当前任务的旧结果也会先隐藏并重新核对服务器当前性。不同Case或快照的回执不能污染当前任务。
- 历史关系仅展示服务器提供的最近历史版本，不宣称提供全部关系时间线。历史内容不自动写入当前编辑清单。
- 保存结果未知时冻结原请求及幂等键，只允许重试原请求或读取服务器状态。明确校验拒绝可重新编辑；版本冲突要求刷新。保存已成功但随后读取失败时不提供重复保存入口。
- 服务端拒绝访问时清空当前编辑和原文、停止操作，并使在途读取失效。普通读取成功不被当成编辑权限恢复；须重新核对任务权限后再打开面板。

## 复审发现并关闭的问题

新增回归先确认失败，再完成修复；并非只检查成功页面。

| 触发条件 | 原问题 | 修复与验证 |
| --- | --- | --- |
| 任务busy状态变化 | 被误当作权限变更，编辑器重载并丢弃本地编辑或在途保存 | busy与实际canWrite分离；操作期间锁定，不重载 |
| PUT等待中关闭面板 | 局部事件丢失，当前任务可能继续显示旧结果 | 捕获根通知回调，在校验成功回执后通知；卸载回归及App作用域回归 |
| 请求校验明确拒绝 | 被误判为未知写入，只能重复错误请求 | 分类validation_error/invalid_request；补SKU控制字符校验和拒绝后可编辑回归 |
| 同键重试取得旧成功回执 | 历史成功回执被显示为最新对应版本 | 成功后重新GET当前head；回执版本2、当前版本3的回归 |
| 保存成功、后续GET失败 | 成功保存可能再次以未知请求重试 | 保留成功通知，锁定编辑，提示刷新；不显示原写入重试入口 |
| 服务端撤权但页面角色未刷新 | 页面仍允许继续填写并重复确认 | 4种访问拒绝、迟到分页和分页拒绝共6项回归；清空并锁定操作 |

独立只读复审的上述问题均已关闭，最终增量复审未发现新的重要问题。此结论只覆盖本步前端及其接口接入，不代替生产安全评估。

## 输入和展示边界

- XLSX行列限制与现有格式兼容，列名使用A至XFD；PDF连续页1至30。混合品目同页PDF需要拆分资料。
- 原文每次显式加载100段，最多25,000段；预览只显示已加载且在选择范围内的前50段，页面明确标识不能证明全量覆盖。
- 本步编辑器创建单段连续品目／SKU摘录。既有多段依据条目不编辑时完整保留，重新编辑须选择当前加载的连续原文；不会静默拼接多个证据。
- 完整对应清单最多140个范围，提交条目JSON字节上限与后端128,000字节限制一致。超量拒绝，不截断保存。
- 动态清单仍最多20品目、100指标。新增对应功能不承诺复杂资料抽取、模型理解或召回准确率。
