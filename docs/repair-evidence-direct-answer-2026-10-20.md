# 资料问答直接答案修复

用户确认：模型读取检索工具返回后，在同一次工具响应中同时提交直接答案和支撑引用；回复突出关键信息，不再展示长证据 ID。

## 行为与范围

`answer_evidence` 新增必填 `answer`，最多 1200 字符，提示通常用一至三句、200 字以内回答，保留单位、含税口径、否定与条件；冲突和多供应商分别说明。服务端继续验证引用归属、已读窗口和完整原文语境。没有有效引用时，服务端只返回固定的未找到原文说明，不展示模型给出的采购事实。

三格 XLSX 合成反例“不含税单价 / 25 / 元/箱”现可返回“供应商的苹果报价为25元/箱，不含税。”，三条来源与位置仍保留。正文不再固定附加摘录清单或完整审查声明；已知证据长 ID 转为短编号，未知长 ID 拒绝。检索降级仍有一行提示，不以隐藏状态冒充语义索引可用。

新答案用 `evidence_answer={version:1,text:...}` 保存。检查点摘要同时绑定答案、完整引用和检索元数据；回读时重新验证原文，再生成展示文字，拒绝只换来源、正文、降级元数据或移除新协议标记。旧记录继续走原摘录渲染，不改写历史。无数据库迁移，复用前端现有文件名/位置按钮，没有布局或样式修改，也不增加模型调用轮次。
