## 修改和约束

- 人工修正来自数据库中完整验证过的审查报告，独立于普通聊天和对话摘要。选择范围为同 Case、同对话、资料快照、清单版本和品目对应 ID/digest；只读 terminal review 的待复核报告。
- assistant 和 dynamic 两种执行器都传入该报告。旧事实按当前规则重验后比较候选字段集合，避免旧规则产生的事实 ID 差异；旧存储和审计保持冻结。
- 最多接受 32 份待复核报告。最新报告必须继承其他报告的全部事实；若存在分叉缺失、超限、摘要不符或校验失败，停止处理，不自动合并。运行期间重复核对候选范围与摘要。
- 沿用 Case 锁内的 `case_busy`、当前权限、attempt/fence；合法 API 在新运行期间不能追加人工修正。不跨新对话、资料、清单或对应版本迁移修正；这些改变后的旧修正只作历史追溯。这是当前边界，不能描述为全任务跨版本人工意见合并。
