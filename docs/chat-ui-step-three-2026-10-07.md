# 聊天前端第三大步交付：交互完善与统一验收

日期：2026-10-07。按已批准的 [三大步计划](superpowers/plans/2026-10-05-chat-ui-implementation.md) 完成第三步（最终步）。

## 已实现

- **记忆偏好设置（MemorySettings）**：账号菜单新增"记忆偏好"入口，对话框内查看/保存/删除三个有限偏好（答复长度、答复格式、答复语言），仅显示后端白名单取值；保存需明确点击（`confirmed=true` + 版本守卫），可选长期/7天/30天有效期并展示当前到期时间；对话框明确说明"不会自动记住对话内容，历史消息与本次上下文分开保存"，不展示未实现的自动长期记忆。Esc 关闭。
- **长历史渐进分页**：消息读取响应新增 `total`（`list_messages` + `MessagesOut`，含后端定向测试）。前端首次加载读取最近一页（≤100 条时全量），历史顶部提供"加载更早消息（剩余 N 条）"渐进入口，滚动位置锚定；跨会话/任务切换重置；发送后优先续读已加载区间，超出 20 页预算自动回退到最近页；超过预算明确报"历史记录较多"，不会把未读历史当空会话。
- **键盘与焦点**：确认审查指标对话框与记忆偏好对话框均支持 Esc 关闭（window 级监听、组件卸载清理）。
- **中文状态区别**：沿用并复查既有的错误/无命中/降级/未完成区分（检索降级由后端答复文本标注"本次采用词法检索"；报告对部分完成、非正式、历史版本分别表述）；本轮未新增未实现功能的按钮或文案。

## 边界与说明

- 渐进分页的"任务标题取第一条消息"在只读最近页时从已加载最早的用户消息派生，加载更早后自动更新；不伪造完整历史。
- 机器重启后本机服务（Docker Desktop、Ollama、API、解析进程、前端）按交接步骤重启后完成本轮验收；Milvus 容器保持退出状态（文档内可见降级），本轮验收不依赖语义检索。
- 演示工作区新增 bob（viewer）成员用于只读验收，保留为演示账号。
- 20 页（2000 条）加载预算沿用第一步契约；发送后的区间续读超预算时回退到最近页并在顶部保留渐进入口。
- 独立封存、真实多品类泛化准确率、远程 CI、生产部署仍属 M5/发布条件，不在前端三大步范围。
