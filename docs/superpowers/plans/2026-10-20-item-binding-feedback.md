# 资料关联操作反馈补修计划

**目标：**落实用户点选的第 4 项“确认关联后看不到成功或错误反馈”。沿用已确认的关联弹窗，反馈固定在底部，提交后立即可见。

**范围：**仅调整 `DocumentItemBindings.vue` 的结果展示、焦点与操作位置，补充现有 CSS 和回归。成功、明确拒绝、保存结果未知、成功回执后读取失败各自表达，保留原有权限、版本、幂等、待确认输入和显式重试规则。其他历史加载、关联版本续用和聊天问答暂不改。

## 设计

- 底部用一个反馈区呈现当前状态，成功为绿色、未完成为红色、结果待核对及保存后读取失败为黄色；不自动消失，不额外叠加第二个确认弹窗。
- 进行中的请求显示进度；请求完成后将焦点移到可见反馈，支持读屏播报。错误和成功消息不再留在表单顶部。
- 刷新记录、原请求重试位于反馈附近。结果未知时只提供核对/原请求重试，不显示另一个普通保存入口。
- 明确错误保留已填内容；成功回执后读取失败，显示已保存且无需重复保存，避免同时出现成功和失败两条相互干扰的提示。
- 开始新的添加、编辑或移除时清理上一次结果，防止旧成功提示继续显示。
