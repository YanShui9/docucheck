# C多品目指标名兼容补修

真实候选为“苹果数量”“T恤含税单价上限”，原件字段为“采购数量”“含税单价”。严格字面匹配会拒绝合法同口径事实。保留已确认清单，不能靠改值通过验收。

1. 回归复现现行规则拒绝品目前缀/单价上限；补数量与单价、错误指标/不同品目、历史版本反例。
2. 新绑定规则v6仅对明确数量和单价名称使用有限别名，允许去掉本品目名称前缀及单价“上限”。不从rule类型猜字段，不支持平均价/总价/预算等换算，不改原文或来源范围。v1-v5按原规则重验，缓存按版本隔离。
3. 必要门禁和复审通过后本地提交、应用并继续真实审查、原文/历史/导出验收。名称兼容超出有限范围仍拒绝，不宣称全行业任意语义通用。
