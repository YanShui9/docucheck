用户已批准[交互设计](../specs/2026-10-10-document-item-binding-design.md)。按当前协作约定在既有开发分支实施，逐个大步骤验证后只提交本地 Git。本计划不应用数据库迁移；运行环境与真实模型验收属于 C。

**目标：** 在中文资料面板确认原文范围对应的采购品目，保留整份清单、版本和证据边界。

**实现范围：** 新增 `frontend/src/itemBindings.ts`（后端契约与请求）、`itemBindingForm.ts`（选择器和输入校验）、`components/DocumentItemBindings.vue`（关系编辑、分页原文、明确确认）。接入 DocumentsPanel 和 App，复用 EvidencePanel 原件预览及既有样式。绑定确认后刷新对话的当前性，不自动发起模型审查。

2026-10-10：B源码与门禁完成，随本步提交本地Git。[交付记录](../../document-item-binding-b-2026-10-10.md)包含218项前端回归、31项后端契约、复审修复和未做的运行应用；C仍待完成。

## B1：契约与资料入口

- [x] 先用资料卡片回归验证中文入口、历史只读和任务切换。
- [x] GET 当前关系，显示未确认/已确认/已失效；按服务器 current/historical 区分，读取失败不冒充未关联。
- [x] 请求使用 OIDC、三个 expected revision 和明确确认；提交完整清单时保留其他文件条目，仅传入请求契约允许字段。

## B2：编辑、预览与确认

- [x] 只使用当前已确认清单中的品目。支持整份文件、XLSX 矩形范围、PDF 连续页；整份单品声明须单独勾选。
- [x] 分页加载同文档原文，选择品目依据和 SKU 依据；可在编辑器内核对原件，不因打开证据而丢失编辑。
- [x] 保留旧产品标识，让用户明确分类为品目、SKU 或未知；不自动转换，不拼接原文数值与锚点。
- [x] 增删改先进入本地待确认清单，再确认整份变更及理由；旧版本不直接转为当前，完整保存不会自动调用模型。
- [x] 覆盖越界输入、空范围、原文不支持、版本冲突、只读、晚响应、未知写入结果的同键重试；卸载或切换任务隔离结果。
