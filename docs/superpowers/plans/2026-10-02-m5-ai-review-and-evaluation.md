# M5-A 委托复核与 M5-B 执行工具

用户于 2026-10-02 明确要求“人工复核，你帮我确认没问题就继续吧”。据此由 AI 对原件和拟定标签逐项复核，并继续 M5-B 的开发验证。旧文档要求等用户亲自填写人工复核的暂停点由此调整；不得把 AI 复核填为独立人类声明。

## 本轮范围

1. 阅读全部 25 份 PDF 的 36 页、13 份 XLSX 的非空单元格，对照 104 格标签、需求、双方冲突与缺失范围。复看六张覆盖所有页的渲染总览。记录经复核的状态、理由及原件/gold 哈希，保留合成、作者已见、AI 复核的来源属性。
2. 用这份固定开发基线推进 M5-B。独立封存数量仍为 0；正式独立验收门槛保持未完成。后续开发集分数与正式验收分开。
3. 实现离线计分器：失败/漏项/重复项/旧版本不缩小分母；必要证据要求页码或单元格及对应原文，冲突须双方；错误引用检查供应商和原件归属；危险“满足”单列。不得用产品规则重新生成 gold。
4. 实现正式 HTTP 上传执行器及默认离线预览：只上传原件和输入清单；新 Case/会话、显式发送、无自动重试、超时取消、保留每次初始运行。运行前固定协议，运行后才评分。真实服务未运行时不宣称业务质量达标。
5. 补 Run API 的安全用量读取，使用原本持久化的 model_id/usage；未知用量或缓存价格记未知。API 不返回连接配置或凭据。

## 校验

先写有代表性的失败/串引用/遗漏测试并观察失败，再实现。测试 HTTP 执行器使用隔离的进程内 API 与可控任务，不调用外部模型。执行现有语料校验、AI 记录版本校验、预览、定向和后端回归、Ruff、pip check、Git 空白检查。

参考 [LangSmith 评测分类](https://docs.langchain.com/langsmith/evaluation-types)及[数据版本管理](https://docs.langchain.com/langsmith/manage-datasets)，于本日核对官方文档。使用本地确定性评分与版本绑定，不增加托管平台。下一次真实运行前说明发送范围、模型请求上限与费用；运行 Docker 或前端前告知。

## 单包首跑暴露的解析兼容问题

真实 m5-c02 首次运行已经保留：9次模型调用、八格均因PDF覆盖不完整而不发布正式结论。源记录确认两个问题：MinerU 4.0.7 将纯文本标题/页脚标为 `paragraph_title`/`footer`；页脚与页码同行，被现有空白列检测当作未验证表格。

修复范围限定为这些真实输出的纯文本块，以及第一/末条布局行中与当前页和总页数准确相符的中英完整页码。标题/页脚仍作为证据保留；混合图片内容、未知块型、错误页码、正文列、页脚的多业务列和漏抽原文仍保持不完整。先写兼容和负向回归，修复后复验真实MinerU，再以新目录/新Case补测；首跑文件不得覆盖或改成成功。

只读代码审查另复现异常消息回执/错Run终态可能漏取消：取得Run ID后立即启用取消保护，每次轮询先验证Run/Case/快照/attempt/revision，再确认终态；补三项真实HTTP路由回归并先观察失败，再修复。未改服务端Run生命周期或增加自动模型重试。
