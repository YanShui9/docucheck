# M3-4 FastAPI 入口实施计划

> 延续已确认的 [Agent 架构](../specs/2026-09-24-agent-first-design.md) 和 M3-3 Run repository。本小步只建立会话、消息和 Run 的 HTTP 入口，上传与 worker 另行实施。

**目标：** 为 Case、Conversation、Message 与 Run 提供可查询、可重放且错误码稳定的 `/api/v1` 接口。

**架构：** `backend/app/db/api_queries.py` 管理 Case/Conversation 创建与按 Case 快照查询；`backend/app/api/main.py` 只负责 HTTP 校验、错误映射和调用既有 `RunRepository`。`create_app(engine=...)` 支持隔离数据库测试，正式服务从 `.env` 读取数据库连接。空 Case 从 revision 0 开始，只有后续上传形成快照后才能提交问题。

**依赖：** FastAPI、Uvicorn、现有 SQLAlchemy Core、Pydantic 与 httpx。依赖安装由用户在 `docucheck` Conda 环境执行。
