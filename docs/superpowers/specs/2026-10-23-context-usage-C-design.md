# C：聊天上下文用量入口

用户于2026-10-23确认“可以试试吧”，批准输入框下方小入口、点击向上展开、沿用绿色白底细边框。本步实施该方案，不重新设计聊天页面。

## 展示与交互

- 常驻入口“上下文 · 估算”，默认收起。点击展开，再次点击、点击外部、Esc关闭；键盘可操作，关闭后焦点回入口。
- 卡片显示当前所选对话最后一个Run的当前attempt中最近一次已记录模型请求；不是下一次预测或整个聊天累计消耗。处理中说明记录可能尚未更新，不保证实时流式。
- 信息量/输入上限以UTF8字节估算，用KB展示；百分比仅表示同口径系统输入额度，进度条最多100%，文字允许超100%。模型配置窗口单独标token，不写死1M、不宣称服务商实测容量。
- 历史状态分别显示本次请求选用近期原话/摘要/任务交接，以及本轮摘要是否完成。未知字段显示“未记录”，不能用0代替未知；旧记录不倒推。
- 无Run显示“发送消息后可查看”；无计量显示“未记录”；加载、失败/重试均局部展示。请求超时20秒，切换任务/对话/Run/attempt时取消并清空，迟到响应不得覆盖；权限丢失清空。
- 桌面卡片宽度不超过360px，向上展开；窄屏不超视口，高度受限内部滚动。

## 数据与边界

增加只读、沿用AuthorizedRoute权限的GET `/agent-runs/{run_id}/context-usage`。响应包含run/case/conversation/snapshot/revision/attempt归属、Run状态及record。仅查询当前attempt，最后事件无可用计量时record=null，不退回旧attempt或旧请求。

record包含seq/created_at/phase/status/provider_called，estimate（input_bytes/limit_bytes/model_window_tokens/output_reserved_tokens/safety_reserved_tokens），实际API usage（可空），memory（近期轮数/摘要条数/交接是否选用，可空），本轮summary_status。严格投影数字和有限状态，不返回提示词、原文、工具参数、摘要正文或指纹。

在请求准入前为Assistant事件附有限memory数字快照，安全诊断白名单显式允许。正式审查没有该快照时显示未记录；摘要调用完成与摘要被选入后续请求分别表达。GET不写业务库、不调用模型，不迁移表。

## 验收

接口验证当前attempt/超过100事件/旧记录/畸形字段/拒绝且未调用/未知usage/权限与删除；页面验证估算单位、超限、摘要两种状态、折叠与键盘、局部失败重试、超时、跨任务对话和attempt竞争。全前端测试与类型构建、受影响后端离线测试、独立复核和桌面/窄屏合成浏览器检查。只本地提交，不合并或部署，不调用真实模型。
