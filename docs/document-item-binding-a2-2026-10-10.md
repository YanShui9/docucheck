## 复审与边界

只读复审与失败回归关闭了以下问题：

- 标题全文“苹果手机，数量20台”不能仅因摘取“苹果手机”就当已覆盖。只有完整、有限的纯品目标题或明确 ASCII 型号结构可以获得标题豁免。
- 将“数量20台”填写为 supplier_sku 不能删除数量反证或取得完整覆盖。
- 带标签中文/复杂型号、直接填写的 `M1`、无标签 `iPhone 17 Pro`/中文型号均不能被误认为没有型号要求。不能可靠表达的非空规格保守转人工；纯品名、采购数量和型号待确认不会当成具体 SKU。
- “苹果 未提供检疫证明”是属性否定，不能误判为否定苹果品目。
- 停在抽取之前的报告不能伪造某品目覆盖；空启用指标范围保持未完成，冻结快照/清单摘要须匹配。
- API 响应 schema 保留新关联身份，避免页面返回与报告导出不一致。

规格自由文本采用有限规则，并非任意型号语义匹配。未支持的复杂规格需要人工核对或拆成明确指标。含其他业务信息的标题需纳入确认事实范围；未关联的资料尾部仍可能藏反证，不能自动忽略。这些保守边界不会因模型声称匹配而放开。
