日期：2026-10-23。用户确认“可以试试吧”后实施，基线为 B2 `9a31601`，位于隔离分支 `codex/context-request-diagnostics`。源码、离线验收和独立复核已完成；仅本地保存，未合并、推送或部署，运行服务没有因此更新。

## 页面行为

聊天输入框下方增加“上下文 · 估算”入口。点击后向上展开白底、绿色、细边框卡片；再次点击、点击外部、Esc 或关闭按钮均可关闭，焦点回到入口。桌面宽度最多 360px，窄屏不超出视口，长内容在卡片内部滚动。

卡片读取当前所选对话最后一个 Run、当前 attempt 的最近一次已记录模型请求。它显示这次请求的估算输入与系统输入额度、配置的模型窗口、输出和安全预留、请求是否进入模型服务、选用的近期原话/摘要/任务交接，以及 API 返回的实际用量。“本次请求选用摘要”和“本轮摘要整理完成”分别展示，不用整理成功推断已经选用。

没有 Run 时显示“发送消息后可查看”，旧记录或缺失字段显示“未记录”。读取失败提供局部重试；20 秒超时覆盖登录令牌获取和 HTTP 请求。关闭、卸载或切换任务/对话/Run/attempt 会取消旧请求，校验响应归属，迟到响应不能覆盖新状态。处理中提示记录可能尚未更新；本步没有持续轮询或下一次请求预测。

## 数字含义与限制

输入量继续采用 A1/A2 的 UTF-8 字节估算，1 KB = 1024 字节。百分比只用估算输入除以同口径系统输入额度；超限可以显示 125%，进度条最多 100%。这不是模型精确 token 占比，也不是整个对话累计消耗。

配置的模型窗口单独以 token 显示，不写死 1M，不代表已实测服务商容量。API 实际用量只显示接口已返回的字段，不倒推缺失值、不把未知填为 0。卡片不提供未经测量的各来源 token 占比；历史选用情况以轮数、条数和是否选用表达。

## 后端范围

新增只读 GET `/api/v1/agent-runs/{run_id}/context-usage`，沿用 AuthorizedRoute 权限，并检查 Case 删除状态。只读取当前 active attempt 的最近至多 128 条模型事件；最后一条没有有效计量时返回空记录，不回退到较旧请求或 attempt。

Assistant 在请求准入前复制有限记忆数字，预算拒绝也可留下这次请求的选用情况。接口按白名单投影数字和状态，不返回提示词、资料原文、工具参数、摘要正文或请求指纹。旧记录缺少明确字节估算口径时显示未记录。GET 不写业务记录、不调用模型，不增加表迁移。
