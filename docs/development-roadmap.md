# DocuCheck Agent 开发路线 v2.0

更新：2026-09-24。本次按用户要求重排开发顺序；本文件取代原“先完成解析，再接 Agent”的阶段计划。架构实施基线为 [Agent 架构 v1.0](superpowers/specs/2026-09-24-agent-first-design.md)。阶段名称变化不意味着功能已完成。

## 当前实际进度

- 已有：Git、Conda Python 3.12、模拟 PDF/XLSX 与标注、MinerU 开发验证、MySQL/Redis/Linux worker 健康检查、基础解析代码。
- 历史开发样例结果：三文件生成 35 个证据块，16/16 标注位置可定位，8 项测试通过。详情见 [环境记录](environment/2026-09-24.md)。本次文档修订未重新执行业务测试。
- 未有：Agent 循环、真实模型调用、RAG、候选事实抽取、规则引擎、会话 API、数据库迁移与前端。
- 已识别缺口：解析 complete 未充分描述忽略内容；证据身份缺少版本边界；PDF 总页数尚需任务级限制；解析未接 Linux worker；应用依赖未完整锁定。

M1 使用本机 CLI 和显式输入快照建立业务闭环；M3 将相同服务接到持久化 API/worker。M1 不宣称断点恢复、正式文件上传或完整八字段验收。每阶段分别报告离线 Fake 测试与真实模型测量。

## 下一步：实施 M1

具体任务见 [最小 Agent 实施计划](superpowers/plans/2026-09-24-agent-mvp.md)：

1. 固定 RunContext、AgentState、工具与回答 schema，补版本/覆盖证据契约。
2. 建立 Fake 和一个真实 Provider 适配器；做工具调用能力探针并锁依赖。
3. 将模拟材料接入 RAG，提供列出资料、检索、读原文工具。
4. 实现内存候选事实抽取、证据验证与规则核验工具。
5. 接 LangGraph 决策—工具—观察—答复验证循环，加入上下文和预算。
6. CLI 连续提问，记录真实调用、结果、证据和失败，更新文档。

下一项实际编码从第 1 项开始，并在同一个 M1 内接通真实 API。若模型配置暂缺，完成不依赖凭据的代码和离线验证，将真实接入门槛保持为未完成，不能默认切 Fake 后宣称成功。

## 后续阶段任务清单

- [ ] 实现另外七字段、限定语、型号关联和完整五状态判定。
- [ ] 修复不支持表格/忽略区域的覆盖语义，完善任务级限额和 XLSX 行表头结构。
- [ ] full 抽取分页扫描全部适用证据；记录每字段覆盖和部分失败。
- [ ] 追问指代、结构化摘要、token 裁剪、standard/thorough 两档、clarification 往返。
- [ ] 测量词法检索 recall@12；按开发集漏召回决定是否实施语义检索扩展。
- [ ] 开发集覆盖无命中、相邻证据、矛盾、歧义、提示注入和版本替换。

### M3：运行服务

- [ ] 数据模型与 Alembic 迁移；MySQL repository 实现 M1 接口。
- [ ] API 实现 Case/文档/会话/messages/agent-runs/证据，错误与幂等约定统一。
- [ ] 文件与索引准备、Agent 执行接 Linux Celery worker；Windows/Linux 分别锁定依赖。
- [ ] Run + Outbox 同事务；领取租约、fencing、取消、重复投递、迟到响应。
- [ ] waiting_user/resume 与 interrupted/retry 持久化；模型 outcome_unknown 可见。
- [ ] 修正、版本失效、删除清理；集成测试覆盖 worker 崩溃与会话恢复。

### M4：可复核的对话产品

- [ ] Vue 上传与供应商/角色绑定，配置发送模型的资料范围提示。
- [ ] 对话、模式选择、轮询进度、澄清回答、取消和重试。
- [ ] 结果矩阵与 Agent 答复共享 CheckResult；PDF.js 原页和 XLSX 来源。
- [ ] 事实修正表单、历史快照、过期提示、XLSX/JSON 导出及公式注入防护。
- [ ] 真实端到端用例贯穿上传、提问、追问、修正、导出。

### M5：正式验收

- [ ] 至少 12 文档包、104 个供应商×字段判例，至少 6 包独立封存。
- [ ] 状态准确率≥85%、确定性结论全部必要证据定位率≥95%、危险误判满足为 0；报告分子分母、未完成项、混淆与失败。
- [ ] Agent 任务成功率、引用错误、调用数、token/费用、延迟与检索召回单独报告。
- [ ] 原 5 文件性能场景预热无缓存真实处理 10 次，至少 9 次≤120秒；失败计入分母。规则修正重算≤2秒。
- [ ] CI 离线回归，真实模型验收显式运行；安装与数据复现文档。

## 计划管理
