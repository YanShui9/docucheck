## 1. 实际做了什么

| 工作 | 实现与约束 | 验证 |
| --- | --- | --- |
| 原文全量覆盖 | 可选/未声明实装容量保留为未知限定语；裸币种总价保留原数值，不除数量或补元/台；其他型号仅在整段明确排除且绑定不同型号时排除。 | 不确定值、混合型号、无绑定、漏数值、XLSX 相邻标签/值和伪造 complete 回归。 |
| 规则与历史 | fields-v4 新契约；交付期限核验供应商承诺；v1/v2/v3 审计重放保留原契约与交期语义，历史不回写。 | 版本、修正、事实序列化及真实 MySQL 回归。 |
| 模型语义与记忆 | 数值和来源先验证，内存限定语/比较符从同一原文确定；未知/近似/可选保持待确认；恢复事实集重新核验实际覆盖。 | 错值/错单位/错来源拒绝，未知语义及ID往返、遗漏第二数值仍partial。 |
| 完整审查进度 | 单家和多家完整八字段按 QuestionScope 推进；缺覆盖最多补抽一次；全部已核验后调用原submit_answer，保留范围、覆盖、预算与取消验证。 | 单字段不被扩为八字段，部分处理不冒充完整，终态无需额外模型调用；记录真实policy事件。 |
| 结构化输出修复 | 仅已收到的抽取 tool_schema 错误纠正一次，仍计入同一调用/token/时限预算；失败usage未知保持未知。 | 认证、超时、网络、output_limit、结果未知不自动重放；值/证据错误不自动修改。 |
| 多轮上下文与来源句柄 | 随工具观察增长，按预算移除完整的旧问答轮；保留当前问题、系统约束和工具成对记录。get_check_results 返回可验证来源ID。 | mandatory context 超限仍停止；伪造/跨供应商/过期ID拒绝；真实来源追问通过。 |
| 诊断与测试隔离 | 诊断只保留有限错误类别、计数和policy；不保存prompt、工具原始参数或凭据。测试Outbox在创建事务中隔离，避免实际dispatcher抢走测试事件。 | 诊断隐私测试、真实 MySQL repository 测试通过。 |
