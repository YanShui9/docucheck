# 测试、业务评估与证据范围

整理日期：2026-10-10。项目将源码回归、服务实连与真实模型业务测量分开报告。

## 1. 三类证据

| 类型 | 可以证明什么 | 不能据此宣称什么 |
| --- | --- | --- |
| 离线回归 | 给定输入下的状态机、授权、版本、工具契约、来源、规则和异常分支 | 上游真实模型质量、生产容量或任意采购文档准确率 |
| 服务实连 | MySQL 事务、Milvus 过滤、队列及浏览器等实际适配路径 | 合成向量测试不能证明语义召回；脚本化 Provider 不能证明真实模型表现 |
| 真实模型开发测量 | 指定模型配置、源码与资料协议下的任务、引用和用量表现 | 作者已见开发集不能替代独立未见测试集 |

## 2. 当前源码门禁

[品目对应 A3 报告](document-item-binding-a3-2026-10-10.md)记录最终 1438 passed / 48 skipped / 网络请求 0，另有隔离 MySQL 16 项及真实 Milvus 3 项。跳过项不是通过项；定向回归和集成数量不能再叠加为独立测试总数。

该报告也保留首次 600 秒超时和最终重跑结果。575.52 秒是本机测试墙钟耗时，不是业务处理时延。最新品目对应源码尚未应用到已有运行服务，仍需前端和该版本端到端验收。

离线复现命令（Python 3.12、已安装开发锁、有效中文字体）：

```powershell
python.exe -m scripts.verify_offline --report data/verification/interview-offline.json
```

使用新的报告路径；脚本不覆盖旧记录。GitHub Actions 执行同一后端命令，前端执行 `npm ci --ignore-scripts`、`npm test` 和 `npm run build`；实时结果见[工作流](https://github.com/YanShui9/docucheck/actions/workflows/offline-ci.yml)。

## 5. 公共证据与本地资产

仓库提供测试、协议、阶段报告、脱敏机器记录和合成截图。报告引用的部分原始日志、数据库快照、截图及历史 ZIP 存于开发机 `data/`，没有全部公开。因此公开仓库支持核对源码和重跑测试，不能声称所有历史结果均可直接从 GitHub 下载并逐字节重现。

可新建合成候选包用于演示（需要中文字体，不调用模型）：

```powershell
python.exe -m evals.candidate_corpus --build --root data/interview-candidates
```

目标目录须未存在。新生成资产不是历史实测原件；上传时只选择 `inputs/` 原件，不把 `gold/`、标签或评估报告作为 Agent 输入。
