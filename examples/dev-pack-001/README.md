# 开发样例 001

这是一组完全虚构的笔记本采购资料，仅用于开发和演示解析、证据定位与五类状态。供应商、型号、价格和条款均为模拟数据，不代表真实客户案例。

- `requirements.pdf`：一页采购需求，含八项要求。
- `vendor-a-quote.xlsx`：模拟供应商 A 报价；有效数据位于 `报价` 工作表的 B4、B6:B9。
- `vendor-a-spec.pdf`：一页产品规格，型号与报价一致。
- `labels.json`：八条人工标准答案；PDF 页码从 1 起，XLSX 使用工作表和单元格定位。

这套样例属于开发集，可用于选择解析配置与调试规则；不能计入独立验收集。缺失质保的标准答案以两份供应商文件均处理成功为前提。
